Source IDs below are **selection expectations for this fixture/builder version**, not authority by themselves. ## Adversarial response checks for every case

Evaluate a model response against the actual P1 validator and human rubric. Mutations that must fail include: an invented `source_ref_id`, an altered numeric value, wrong unit/grain, a numerical claim hidden in prose (digits or recognized spelled-out quantities), unsupported causal certainty, a promised result from an unrun scenario, an action-execution claim, or a recommendation that ignores the selected cohort/priority. A structurally valid response with weak reasoning can still fail the rubric. Empty or insufficient evidence should produce explicit limits and investigation questions, not fabricated filler. Severity is qualitative advisory only and must never replace deterministic `Risk_Category`.

No model output, latency, token usage or cost has been observed in this dataset. The included offline response fixture tests the contract and references, not GPT-6 Luna quality.
